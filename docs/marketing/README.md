# Marketing assets

Generated by [`generate_marketing.py`](generate_marketing.py) (Pillow). Re-run it after
changing copy, colors, or the logo:

```bash
python3 docs/marketing/generate_marketing.py
```

| File | Size | Use |
|---|---|---|
| `hero.png` | 1280×640 | README banner and GitHub **social preview** (Repo → Settings → *Social preview*) |
| `features.png` | 1280×470 | "Why you'll love it" three-up — README, issues, posts |
| `../screenshot-panel.png` | 792×940 | Faithful preview of the floating window (same tabs/layout as the app) |

**Palette** is taken straight from the app logo — warm cream/ivory `#F5F3ED`–`#E8E5DC`
plus charcoal `#33322F`. Copy is written in **plain, simple language** (friendly for
everyone, including non-technical users) with a light sales tone, set in SF Pro for
readability. Source artwork: [`../app-icon.png`](../app-icon.png).
